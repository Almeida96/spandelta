## 0.1.0 · 2026-11-03

- Import OTLP trace files or receive live JSON and Protobuf batches over HTTP with gzip support.
- Keep named release cohorts in SQLite with atomic imports, duplicate detection and conflict rollback.
- Compare operation latency and error rates with configurable sample requirements and CI exit codes.
- Inspect trace timelines with parent warnings and overlap-aware child accounting.
- Export self-contained HTML reports with observed candidate traces and stable identifiers.
- Expose datasets, comparisons and trace evidence through a read-only MCP stdio server.
